## 📘 Overview  

**Café Management System** is a **web-based ordering and billing application** built using **HTML, CSS, and JavaScript**.  
It enables users to browse a digital café menu, add items to the cart, and view automatic price calculations — offering a modern and efficient café experience.

---

## 🚀 Features  

- 🔐 **User Authentication** — Secure login and signup functionality for customers.  
- 🍽️ **Digital Menu System** — Interactive menu showcasing café items with prices.  
- 🛒 **Add-to-Cart & Billing** — Real-time order updates and dynamic price calculation.  
- ✅ **Form Validation** — Ensures accurate and complete input during user interaction.  
- 💻 **Responsive Design** — Works seamlessly on desktop and mobile devices.  
- ⚡ **Smooth User Interface** — Lightweight and optimized for fast performance.
